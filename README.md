# AutumnOS-RT

The RT-Thread based version of AutumnOS for low-RAM processors, This operating system aims to provide users with a smooth experience and performance, even with minimal RAM, by reducing unnecessary system services and light UI.

--------------------------------------------
Technical information:

- Allwinner D1 and ESP32 support
- Memory allocator
- SIM800L/Battery/Sound drivers
- Millisecond timer support
- DFS (RT-Thread Embedded filesystem) support
- AutumnCore lite version
- Task handler
- Kernel panic handler
---------------------------------------------

Requirements: 
- RAM lower than 1GB
- ESP32 or Allwinner D1 processor (SoM or SoC)
